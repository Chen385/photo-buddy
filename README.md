# 照片搭子 · Photo Buddy

> 照片你发，BGM 我挑。给每一张照片，配一点情绪。

一款纯静态网页应用：上传 1–3 张照片，选择配文模式，生成有网感、不尬的文案，并从免版权曲库智能匹配 15 秒 BGM，支持试听、换一版、复制文案、查看推荐理由与本地音乐上传。

## ✨ 功能清单

- **照片上传**：支持 JPG / PNG / WebP，单张 ≤ 25MB；缩略图预览、单张删除、继续添加；照片仅在浏览器本地读取，不上传服务器。
- **补充描述**：选填，两句以内的心情/场景说明，帮助文案与配乐更贴合。
- **三种配文模式**
  - 帮我决定：折中随机，自动挑选风格；
  - 认真配：贴合画面情绪与描述；
  - 放开整活：偏玩梗、网感路线。
- **配文生成**
  - 已配置兼容 OpenAI 格式的视觉模型接口时，**真实调用 AI 识图**生成文案；
  - 未配置或调用失败时进入**演示模式**，由本地规则模板兜底生成，界面明确标注「演示模式」，不会假装调用成功。
- **BGM 曲库**：8 首浏览器内置音源实时合成的免版权 15 秒片段，按画面情绪与模式匹配；不含任何受版权保护的现成歌曲。
- **播放控制**：试听 / 暂停、进度条拖动、时长显示、唱片旋转、波形高亮；可换一版（重新生成文案并换曲）。
- **复制文案**：一键复制到剪贴板（含旧浏览器降级方案）。
- **推荐理由**：展开查看「为什么配这首」，结合画面冷暖/亮度/关键词说明匹配依据。
- **本地音乐上传**：可选择本机音频文件，仅在浏览器内播放，不上传。
- **响应式**：手机竖屏与电脑宽屏自适应，奶油白 + 浅紫色视觉风格。

## 🧪 演示模式说明

GitHub Pages 为纯静态托管，无法运行后端服务，也不应在公开仓库中硬编码任何 API 密钥。

- 默认状态下应用运行在**演示模式**：文案由本地模板规则生成，情绪判断基于画面主色/亮度/冷暖的本地启发式分析，曲目匹配基于关键词与情绪标签。
- 如需真实 AI 识图：在页面底部点击「演示模式 · 未配置 AI 接口」打开设置，填写兼容 OpenAI `chat/completions` 格式的视觉模型接口地址、模型名与 Key。凭证仅保存在本机浏览器 `localStorage`，不会写入代码仓库；若接口不可用或调用失败，自动回落演示模式并在界面标注原因。

## 🚀 本地运行

纯静态页面，无需构建，任选一种方式：

```bash
# 方式一：Python
cd photo-buddy
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080

# 方式二：Node
npx serve .
```

也可以直接用浏览器打开 `index.html`（部分浏览器对本地 `file://` 下的音频/图片读取有限制，推荐用本地服务器）。

## 📁 目录结构

```
photo-buddy/
├── index.html              # 页面结构
├── README.md
└── assets/
    ├── css/style.css       # 奶油白 + 浅紫视觉样式，响应式
    └── js/

        ├── audio-engine.js # Web Audio 离线合成 + 播放器
        ├── caption-engine.js # 画面分析 / AI 调用 / 本地兜底 / 匹配
        └── app.js          # 交互主逻辑
```

## 🔒 安全与隐私

- 照片、补充描述、本地音频均只在本机浏览器处理，不向任何服务器上传。
- AI 接口凭证只存于本机 `localStorage`，仓库代码中不包含任何密钥。
- 曲库曲目由 Web Audio 实时合成，无第三方音频资源、无版权音乐片段。

## ⚠️ 已知限制

- 演示模式下的「识图」是本地颜色/关键词启发式判断，不是真正的视觉理解；真实识图能力依赖用户自行配置可用的视觉模型接口。
- 合成音轨为程序化旋律，音色与编曲精细度有限，仅作为演示占位用途。
- AI 接口受浏览器跨域（CORS）限制：部分服务商不允许浏览器直连，此时需自备代理；不可用时应用自动回落演示模式。
